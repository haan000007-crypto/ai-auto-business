# AI Auto Business

Monorepo for building and operating AI-powered business automations.

## Structure

- `apps/` — end-user applications and APIs
- `packages/` — shared UI, database, workflow, AI, and integration modules
- `workers/` — asynchronous/background processing
- `infrastructure/` — deployment and infrastructure definitions
- `docs/` — project documentation
- `tests/` — cross-package tests

## Getting started

Install dependencies with your preferred package manager, then run the relevant workspace scripts.
